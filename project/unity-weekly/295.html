Shader Build Settings and fast compilation

Shader Build Settings and fast compilation - Graphics Product Updates - Unity Discussions

Unity 6.6と6.7で利用できるShader Build Settingsと、シェーダーのコンパイル時間を短縮する設定を紹介するディスカッションです。

  • Configuring the target compiler with Shader Build Settings
    • Unity 6.6から、WindowsのBuild ProfileごとにDXCを選択できる。対応はDX12のみで、DX11を併用するとFXC用のシェーダーもコンパイルするため、ビルド時間が増える場合がある
  • Fast shader builds
    • Unity 6.7のFast Buildは、対応するキーワードを動的分岐へ変換してバリアントを削減する
    • URP 3D Sampleでの試験では、クリーンビルドの時間を約75%短縮できたと報告している
  • Keyword exclusion
    • Unity 6.6から、不要なキーワードや組み合わせを除外できる
    • 必要なバリアントが欠落する可能性があるため、実行時に使わないと確認できたものだけを除外するよう注意を呼びかけている
  • Constant defines
    • バリアントを増やさずにビルド時の分岐を設定する、独自のシェーダー定義をEditorから指定できる

Performance Testing Framework 3.7.0 has been released - Performance & Profiling Product Updates - Unity Discussions

Performance Testing Framework 3.7.0（com.unity.test-framework.performance）のリリースを紹介しています。

Unity 6.0と6.3向けにリリースし、Unity 2022.3 xLTSのサポート終了に伴って最小対応バージョンをUnity 6.0に引き上げたことが主な変更です。 このバージョンにはまだbreaking changesはなく、2022.3のプロジェクトへ強制的に導入することは可能だと説明しています。

Module state and streamlined development with Cloud Code 3.0

Module state and streamlined development with Cloud Code 3.0 - Cloud Code - Unity Discussions

Unity 6.7以降を対象としたCloud Code 3.0の正式パッケージ公開を紹介しています。

  • Stateful Cloud Code
    • [StateScope]でプレイヤー単位またはMultiplayerセッション単位の状態を呼び出し間で保持できる
    • 対象プレイヤーへのプッシュメッセージ、サーバータイマー、関数単位のアクセス制御に対応した
  • Native Authoring: Cloud Code modules in the Editor
    • Unityプロジェクト内でモジュールを作成し、型付きのクライアントを自動生成できる
  • The local Cloud Code server
    • デプロイせずにローカル実行とデバッグができ、再コンパイル後は実行中のサーバーへ変更を反映する
    • Observability Logsウィンドウから、デプロイ済みのスクリプトとモジュールのログを確認できる
  • Multiplayer Play Mode integration
    • ローカルまたはリモートのCloud Codeを使うシナリオを設定し、複数プレイヤーで検証できる
  • Also in 3.0
    • ModuleHostWarmupによる事前起動に対応し、ワーカーのメモリを256 MBから512 MBへ増やした
  • Agent Skills
    • Unityのマルチプレイヤーサービスを使う開発向けに、build-live-gameスキルを公開した
  • Before you upgrade
    • Unity 6000.7以降と.NET 10 SDKが必要
    • 一部の旧APIを削除し、Unity.Services.CloudCode.Apisのクラスを内部化したため、インターフェース経由の利用へ移行が必要

Prediction in GameObject Netcode - GhostObjects Released

Prediction in GameObject Netcode - GhostObjects Released - Multiplayer & Networking Product Updates - Unity Discussions

Unity 6000.7以降向けのUnity Netcode 7.2.0とNetcode for GameObjects 3.2.0で、GhostObject APIが利用可能になったことを紹介しています。

  • Package versions
    • Netcode for EntitiesをUnity Netcodeへ改称した。パッケージ名のcom.unity.netcodeは変更なし
    • GameObjectにGhostObjectとGhostBehaviourを追加し、予測、ロールバック、量子化、差分圧縮を利用できる
  • Since our last dev log: Unity Netcode 7.2.0
    • Rigidbodyの予測とロールバックを支援する物理処理、遅延スポーン、親子関係の変更の予測と同期などに対応した
  • How this fits with Netcode for GameObjects
    • 同じGameObject上でNetworkObjectとGhostObjectを併用できる
    • 既存の接続フローを維持しながら、NetworkTransformをGhostObjectのTransform同期へ置き換える構成を紹介している
  • Next steps
    • オブジェクトプールや予測誤差の平滑化などを今後の改善項目として挙げている
  • Unity 7
    • 2つのNetcodeパッケージのコードを統合する方針で、いずれかの機能群を廃止するものではないと説明している

Unity CLI 1.0.0-beta.16 is rolling out

Unity CLI 1.0.0-beta.16 is rolling out - Unity Editor Product Updates - Unity Discussions

Unity CLI 1.0.0-beta.16の公開をアナウンスするディスカッションです。 Editorのダイアログ操作や起動中のEditorを使ったビルドを追加し、自動化スクリプトに影響する出力形式と終了コードも変更しています。

  • Highlights
    • 対応するEditorでは、unity command editor dialogでダイアログを確認し、unity command editor dialog answer <id> <button>で応答できる
    • unity build --targetが起動中のEditorでビルドする。タイムアウトやCtrl+Cは待機を終了するだけで、Editorやビルド自体は停止しない
    • unity skill sync [client]で1つのエージェントのスキルを確認なしに更新する
    • unity vcs diffが変更された参照先のアセット名を示し、unity vcs summarize --objectsでオブジェクト単位に変更を要約する
  • Also new
    • Cloud Buildのターゲット、リポジトリ、署名用認証情報の設定をCLIから実行できる
    • クラウド連携プロジェクトの作成時にRemote Configのliveops_enabledとCloud Saveのスロットを追加する。--bareで省略できる
  • Changes to check if you script the CLI
    • コマンドの出力を実行中にストリーミングし、コマンド自身の終了コードを返す
    • EditorのJSON出力からsuccess、command、parameters、targetのラッパーを削除した。--result-onlyは変更なし
    • Editorが処理中の場合は終了コード17、モーダルダイアログで停止している場合は18、オフラインやDNS、プロキシ関連のエラーは7を返す
    • setup allはシェルを利用できるエージェントへMCPを自動登録しない。必要な場合はunity mcp configureで設定する
  • Notable fixes
    • URPマテリアルのアップグレードダイアログによる停止、指定changesetと異なるEditorビルドのインストール、SOCKSプロキシ経由のダウンロードなどを修正した

Unity CLI 1.0.0-beta.17 is rolling out

Unity CLI 1.0.0-beta.17 is rolling out - Unity Editor Product Updates - Unity Discussions

Unity CLI 1.0.0-beta.17の配信開始をアナウンスするディスカッションです。

  • Highlights
    • プラグインの依存関係の宣言に対応し、依存先からインストールや更新を実行する
    • CLIからPipeline Automationアプリと下書きバージョンを作成できる
  • Also new
    • Hubでクラッシュレポートの送信を無効にすると、CLIにも反映する
  • Changes to check if you script the CLI
    • 複数のコマンドグループで、引数不足や余分な引数がある場合の終了コードを2に変更した
    • --git-token-from-stdinへの入力が空の場合は終了コード4で失敗し、保存済みGit認証へフォールバックしない
    • 非対話環境でリモートリポジトリを削除するロールバックには、--yesが必要に
    • Cloudプロジェクト名が一意に解決できない場合や通信失敗時の終了コード、TSVとJSONの出力形式を変更した
  • Notable fixes
    • 引用符付きの-projectPathで起動したEditorの検出、JUnitレポートによるNUnitレポートの上書き、負荷が高い環境でのテスト監視の取りこぼしなどを修正した

Unity Pipeline 0.10.0-exp.1 is out!

Unity Pipeline 0.10.0-exp.1 is out! - Unity Editor Product Updates - Unity Discussions

Unity Pipeline 0.10.0-exp.1の公開をアナウンスするディスカッションです。 CLIからのProfiler記録やメモリスナップショット取得、Editorウィンドウのキャプチャなどを追加し、引数の命名規則や設定ファイルの保存先も変更しています。

  • New
    • Editorまたは接続した開発用PlayerのProfiler記録と、.snap形式のメモリスナップショット取得に対応した
    • 任意のEditorウィンドウやSceneビューのキャプチャ、URPとHDRPでのオーバーレイUIを含むカメラキャプチャに対応した
    • script evalがusing、メソッド、型、awaitを含むスクリプトに対応した。--fileによるファイル実行や--dry-runによるコンパイルのみの確認もできる
    • --format human|tsv|jsonで出力形式を指定し、実行中にCLIへストリーミングする
    • Unity 6.3以降のツールバーからPipeline Serverを起動、停止できる
  • Changes
    • コマンド引数と構造化引数のキーをkebab-caseに統一し、古い表記は拒否する。コマンド名と結果フィールドは変更なし
    • 有効化はenabled、出力先はoutput-pathなど、同じ概念の引数名を統一した。公開済みのunity CLIは1.0.0まで動作する
    • 未知の引数やネストしたキーはINVALID_COMMAND_ARGSとして拒否し、候補を提示する
    • 独自コマンドの引数名としてformat、json、fields、verbose、omit-nullsを使用できない
    • プロトコルの終了コードをCLIに合わせ、サーバー自身の終了コードは100以降にした。特定のコードを判定するスクリプトは更新が必要
    • Editorサーバー設定をProjectSettings/からユーザー単位のUserSettings/へ移動した。コミット済みの設定はプロジェクトの全員には適用されなくなる
    • キャプチャの相対--output-pathの基準をAssets/からプロジェクトルートへ変更した
    • capture screenshotとscript eval_fileを非推奨にし、それぞれcapture game_viewまたはcapture scene_view、script eval --fileへの移行を案内している
  • Fixes
    • batchmodeでのEditorの予期しない終了、スクリプト再読み込み後の古いリスナー、コンパイル完了前の成功報告を修正した
    • Multiplayer Play Modeのクローン起動や、ドメインリロードを伴うテスト結果の重複、欠落などを修正した
  • Upcoming API change in Unity Pipeline 1.0.0: a smaller public API
    • 今後の1.0.0では、サーバー実装、応答モデル、コンパイル処理などの内部用C#型を公開APIから削除する予定だとしている
    • JSONの応答形式は変更しない一方、対象のC#型に依存するコードは1.0.0へ更新するとコンパイルできなくなるため、依存箇所の確認を呼びかけている
