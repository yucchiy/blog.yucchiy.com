Culling Update - now and next

Culling Update - now and next - Graphics Product Updates - Unity Discussions

Unityのカリングの現状と今後の改善方針を紹介するディスカッションです。 今後は新機能の追加よりも、既存機能の改善を優先するとしています。

Umbraを使ったベイク済みのオクルージョンカリングは、Unity 6.7で非推奨になります。 新規プロジェクトでは設定UIを表示しなくなる一方、利用中のプロジェクトは引き続き動作し、6.7のライフサイクルを通じてUmbraをサポートすると説明しています。 後継となる仕組みは検討中とのことです。

GPU occlusion cullingは開発を継続中の機能と位置づけています。 インスタンシングを多用する高密度なシーンでなければ、可視性の判定コストが削減効果を上回る場合があるため、基本的に無効にすることを推奨しています。

Unity 6.6では、画面上のサイズが小さいメッシュをGPU Resident Drawerの描画対象から除外できるようになりました。 シャドウを投影するオブジェクトも対象で、カスケードごとにしきい値を設定できます。

今後の検討項目として、モバイルGPU向けのオクルージョンカリング、複数カメラやXRのビューでのカリング処理の共有、独自の可視性判定を組み込めるスクリプトからの制御を挙げています。

  • What would help us
    • Baked occlusion culling: 利用している場合、対象のコンテンツと代替手段に必要なものを知りたい
    • Custom or third-party visibility systems: 独自実装やアセットストアの製品を使っている場合、その内容と必要になった理由を知りたい
    • Mobile: カリングに求める要件とプロジェクトの特徴を知りたい
    • GPU occlusion culling: 利用している場合、使用感とプロジェクトの種類を知りたい

[INFO] iPadOS 27 & SDK 27 adaptability changes & iPhone Duo updates

[INFO] iPadOS 27 & SDK 27 adaptability changes & iPhone Duo updates - Mobile - Unity Discussions

iPadOS 27とSDK 27への対応を案内するスレッドで、UISceneSizeRestrictions対応の提供時期を回答した2026年11月13日の投稿です。 横向き固定のゲームを開発する利用者からの質問に、Unityのスタッフが答えています。

UISceneSizeRestrictionsの実装は進行中で、まず最新のUnityバージョンで提供し、その後まもなく6000.3へバックポートする計画だとしています。 App Storeへの提出にSDK 27が必要になる見込みの2027年4月より前に、確実に提供すると説明しています。

横向き固定のゲームでレターボックスを使う対応がApp Storeの審査を通るかという質問には、判断するのはAppleでありいつでも変わりうるため、100%の確証はないと答えています。 そのうえで、現時点ではレターボックスは許容される方法であり、審査の妨げにならないと強く確信しているとのことです。

同じ日の別の返信では、公式対応の前にUISceneSizeRestrictionsを独自に設定する場合の既知の問題を説明しています。 最小サイズに大きな値を設定すると、画面の向きを変えたときなどにOSがウィンドウをリサイズしても、描画ビューがサイズを再計算しない場合があります。 その結果、Unityの表示の一部が見えなくなり、片側に黒い帯が出るとのことです。 妥当な最小サイズであれば問題にならないはずだとしています。

Unity Pipeline 1.0.0 is out - Unity Editor Product Updates - Unity Discussions

Now Available: Unity Hub 4.0.0

Now Available: Unity Hub 4.0.0 - Unity Hub - Unity Discussions

Unity Hub 4.0.0の正式リリースをアナウンスするディスカッションです。 Hubをネイティブアプリとして作り直しており、Unityのテストでは起動が約10倍速くなり、メモリ使用量も減ったとしています。 ダウンロードサイズはUnity Hub 3の約4分の1で、Windowsでは248 MBから58 MBになりました。 更新するとUnity Hub 3を置き換えます。

  • The Unity CLI replaces the Hub’s command-line mode.
    • Hubの--headlessコマンドを使うスクリプトは、Unity CLIへの移行が必要になる
    • Hub自身のコマンドラインモードが必要な場合に向けて、Unity Hub 3の最終版である3.22.6を引き続きダウンロードできる
  • Git, the way you already sign in.
    • OSの認証情報マネージャーに保存したGitHubとGitLabのサインイン情報を使い、ターミナルやIDEと共有する
    • SSHのリモートを使うプロジェクトに対応し、OrganizationやプロジェクトごとにGitアカウントを選べる
  • Fewer warnings you’ve already seen.
    • Settings > NotificationsのWarningsから、プロジェクトとテンプレートの警告を非表示にできる
  • More ways to run it on Linux.
    • AppImage、.deb、.rpmに加えて、Flatpakでも配布する
  • Crash reports and usage analytics
    • Settings > Security & PrivacyのSend crash reportsで、Hubと同梱のUnity CLIによるクラッシュレポートの送信を無効にできる
    • サインイン中は利用状況分析の設定をUnityアカウントに保存し、HubやCLIを使うすべての端末で共有する

MemoryPackで同じ値をシリアライズしてもバイト列が変わる原因と対処法

MemoryPackで同じ値をシリアライズしてもバイト列が変わる原因と対処法 - きゅぶろぐ
